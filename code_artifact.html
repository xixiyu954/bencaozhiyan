如何让全校师生通过 HTTPS 公开访问？

本控制台为单文件纯前端网页（无需后端服务器与数据库），只需将本 HTML 文件重命名为 index.html，上传至以下任意免费静态托管平台即可自动获得全球可访问的 HTTPS 链接：

  1. GitHub Pages（推荐）：新建公开仓库 → 上传 index.html → 在 Settings → Pages 中开启部署，几分钟即可获得 https://用户名.github.io/仓库名/。
  2. Cloudflare Pages / Vercel：直接拖拽文件夹上传，自动签发 SSL 证书并提供高速 HTTPS 域名，微信/手机浏览器均可直接打开。
  3. 校内/实验室静态服务器：直接放入 Nginx 或院系教研室网站的静态目录即可通过校园网访问。

提示：每位同学打开链接后，实验数据会安全保存在各自浏览器本地，也可通过右上角“导出存档 / 导入存档”在小组 4 名成员间同步共享实验进度。
